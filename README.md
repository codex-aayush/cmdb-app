# CMDB Application

This is a Configuration Management Database (CMDB) application.

## Prerequisites

- Java 11 or higher
- Maven 3.6 or higher

## Building the Project

To build the project, run:

```bash
mvn clean install
```

## Running the Application

To run the application, execute:

```bash
mvn exec:java -Dexec.mainClass="App"
```
